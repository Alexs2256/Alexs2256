An agentic RAG system that allows users to interact with Lydia from *The Elder Scrolls V: Skyrim* while maintaining conversational context and persistent game state.

* Architected a **LangGraph agentic system** with an LLM router for lore, game-state, and chit-chat classification.
* Built a RAG pipeline using **Gemini embeddings, pgvector, cosine similarity search, and conversational query reformulation**.
* Designed a nested LangGraph subgraph for **7 game-state sub-intents** backed by transactional PostgreSQL writes.
* Implemented **multi-model fallback chains, exponential-backoff retries, and automatic quota-exceeded handling** for LLM reliability.
* Evaluated the RAG system across **27 grounded, boundary, and trap queries**, achieving **100% LLM-judged faithfulness** in the current evaluation set.
